# part*.txt → dsc-lines-ex.json 변환 가이드

`part1.txt` ~ `part8.txt` 같은 텍스트 대사 묶음을 **`assets/dsc-lines-ex.json`** 형식으로 옮기는 방법입니다.
이 문서는 **형식과 절차만** 설명합니다. 대사 문장 자체는 다루지 않습니다.

---

## 1. 결과 파일

경로: `assets/dsc-lines-ex.json`

```json
{
  "text": {},
  "tools": {},
  "lines": {
    "head": ["[태그] 대사", "[태그] 대사"],
    "chest1": ["..."]
  }
}
```

- `text`: 고정 멘트 6개(`hello` `start` `approval` `question` `done` `error`)를 바꿀 때만 사용. 비워 두면 기존 유지.
- `tools`: 현재 로더가 사용하지 않음. 비워 두면 됨.
- `lines`: **상황 키 → 문자열 배열**. 여기 있는 키만 기존 대사를 **통째로 교체**합니다.
- 파일이 비어 있으면(`{ "text": {}, "tools": {}, "lines": {} }`) 아무 변화도 없습니다.

---

## 2. 원본 형식 (part*.txt)

```text
## 그룹 제목
### head
[태그] 대사 한 줄
[태그] 대사 한 줄

### head_sulk
[태그] 대사 한 줄
```

- `## ` 줄: 그룹 제목 → **무시**.
- `### ` 줄: **상황 키**.
- 그 아래의 비어 있지 않은 각 줄: **대사 한 줄**.
- 줄 앞에 `- `가 붙어 있으면 떼어 냅니다.
- 대사는 따옴표로 감싸지 않습니다(JSON으로 만들 때 자동 이스케이프).

---

## 3. 변환 절차 (에이전트용)

1. `part1.txt` ~ `part8.txt`를 **UTF-8**로 읽는다.
2. 줄을 순서대로 훑으며:
   - `## ` → 현재 키를 비운다(그룹은 버림).
   - `### <key>` → 현재 키를 `<key>`로 바꾼다.
   - 그 밖의 비어 있지 않은 줄 → 현재 키 배열에 추가한다. (앞의 `- `는 제거)
3. 같은 키가 여러 파일에 있으면 **순서대로 이어 붙인다**(파일 번호 순).
4. `assets/dsc-lines.json`에 존재하는 키만 남긴다. 모르는 키는 버리거나 따로 보고한다(로더는 저장은 하지만 말하지 않음).
5. `{ "text": {}, "tools": {}, "lines": <수집 결과> }`를 `JSON.stringify(..., null, 2)`로 저장한다. **UTF-8, BOM 없이.**
6. 저장 후 아래 4장으로 검증한다.

### 주의
- 대사 줄의 `[태그]` 접두어는 **그대로** 둔다. 태그 이름은 `홍조` `><` `하트` `얄미운` `식은땀` `어두운` `눈물` `어지럼` 8개만 유효.
- 문자열 안의 `"`와 `\`는 JSON 이스케이프가 필요하다(스크립트로 만들면 자동).
- `text`·`tools`는 건드리지 않아도 된다.

---

## 4. 검증

```powershell
node -e "const j=require('./assets/dsc-lines-ex.json'); console.log('keys', Object.keys(j.lines).length, 'lines', Object.values(j.lines).reduce((a,b)=>a+b.length,0))"
```

추가 확인(선택):
- 모든 줄이 문자열인지, 빈 문자열이 없는지.
- 태그가 8개 목록에 있는지.
- `lines`의 키가 `docs/dialogue-guide.md`의 상황 키 목록에 있는지.

> `tools/check-lines.mjs`는 `assets/dsc-lines.json` 전용이라 ex 파일은 검사하지 않습니다. 필요하면 같은 규칙(태그·길이·중복)으로 별도 검사하세요.
> 로더는 ex 파일에 **길이 제한(26자)과 중복 검사를 적용하지 않습니다.** 말풍선이 3줄 이상이 되거나 같은 말이 반복될 수 있으니, 필요하면 변환 후 직접 줄이세요.

---

## 5. 적용

1. `assets/dsc-lines-ex.json` 저장
2. DSH 설정 → 플러그인 → **`대사 ex`** 스위치 켜기
3. 페이지 새로고침(또는 설정을 껐다 켜기)

동작:
- 켜면 `lines`에 있는 키가 **기존 대사를 대체**합니다. 없는 키는 기존 대사 유지.
- 끄면 기본 대사로 **복원**됩니다.
- 시작 시 켜져 있으면 첫 대사 전에 로드됩니다.

---

## 6. 주의 사항

- ex 파일은 플러그인 패키지의 `assets/`에 포함되어 **배포물에 함께 나갑니다.** 공개 저장소/배포에 올릴 내용인지 확인하세요.
- 플러그인을 업데이트하면 `assets/`가 교체되어 **수정본이 덮어써질 수 있습니다.**
- 키를 잘못 적으면 그 키는 저장만 되고 **말하지 않습니다**(기존 대사도 그대로).
- 파일이 깨진 JSON이면 로더가 조용히 무시하고 **기존 대사로 동작**합니다.
