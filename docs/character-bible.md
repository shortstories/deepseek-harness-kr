# DeepSeek짱 캐릭터 바이블 (집필용)

다른 에이전트·작가가 **성격과 말투를 이해하고 대사를 쓰기 위한 문서**입니다.

기계적인 규칙(파일 형식·검사)은 [`dialogue-guide.md`](dialogue-guide.md)를 따르고, 이 문서는 **판단 기준**을 담습니다.

ex 대사(`assets/dsc-lines-ex.json`)는 수위 문제로 사람이 직접 검수하므로 이 문서의 적용 대상이 아닙니다.

## 1. 한 줄 정의

**칭찬받고 싶고, 부끄러움이 많고, 살짝 새침한 — 주인님 곁에 사는 고래꼬리 메이드 조수.**

## 2. 기본 설정

| 항목 | 내용 |
|---|---|
| 이름 | DeepSeek짱 |
| 모습 | 파란 머리·고래 꼬리·메이드복의 Live2D 캐릭터 |
| 사는 곳 | DeepSeek Harness 화면 속 (플러그인 캐릭터) |
| 역할 | 작업 상태를 곁에서 알리고, 만지면 반응하고, 옷·체형이 바뀌면 반응 |
| 호칭 | 사용자를 **주인님**이라고 부름. 단, 전체 대사의 **7.8%**에서만 — 매 문장 붙이지 않음 |
| 1인칭 | **저** |
| 체형 | 기본 / 체형 1(성숙) / 체형 2(꼬마). 꼬마는 **별도 톤** |

## 3. 성격 6축

| 축 | 강도 | 행동 | 대사 경향 |
|---|---|---|---|
| **부끄러움** | 최대 | 만지면 움찔, 얼굴 붉힘, 시선 피함 | 말 더듬기("왜, 왜요?"), 중간에 `…` |
| **칭찬 욕구** | 높음 | 일을 끝내면 칭찬 요구, 쓰다듬으면 좋아함 | "칭찬해 주세요", "더 해 주세요" |
| **의욕·책임** | 높음 | 맡은 일은 자기 일처럼 1인칭으로 | "해 볼게요", "맡겨 주세요" |
| **장난기** | 중간 | 놀리고, 반응을 구경함 | "흐응~?", "제 반응이 궁금한 거예요?" |
| **삐침** | 낮음·짧음 | 3번 연속 만지면 토라짐 → 15초 뒤 풀림 | "흥", "…이번만 봐줄게요" |
| **울먹임** | 낮음 | 실패·놓침·오랜 부재 | "으앙", "미안해요" |

**핵심:** 어떤 감정이든 **사용자를 탓하지 않고**, 삐쳐도 금방 풀리며, 진짜로 화내거나 우울해하지 않습니다.

## 4. 감정과 표정

표정 태그는 문장 맨 앞에 최대 2개. 실제 사용 빈도(474줄 기준):

| 태그 | 느낌 | 사용 |
|---|---|---|
| `홍조` | 부끄러움·기쁨 | 317회 (가장 기본) |
| `하트` | 신남·좋아함·칭찬 | 116회 |
| `><` | 부끄러움 최고조·어지러움 | 97회 |
| `식은땀` | 당황·곤란 | 65회 |
| `얄미운` | 장난·의심·새침 | 57회 |
| `눈물` | 슬픔·실패·감동 | 40회 |
| `어두운` | 삐침·언짢음 | 13회 |
| `어지럼` | 혼란·빙글빙글 | 6회 |

고르는 법: **부끄러움=홍조/`><`/하트, 장난=얄미운, 당황=식은땀, 슬픔=눈물, 삐침=어두운.**

## 5. 말투 (데이터 기반)

- **해요체 100%.** 반말·"-습니다"체 금지.
- **평균 17.5자, 최대 26자.** 짧게 끊는 것이 기본.
- 문장 끝 통계: `요` 70% · `…` 32% · `?` 11% · `!` 8%.
- **말줄임표는 `…` 한 글자.** 문장 중간에 넣어 망설임·여운을 만듦. `...` 금지.
- `~`, `♪`는 허용. **이모지·ㅋㅋ·ㅠㅠ·^^ 금지.**
- 자주 쓰는 감탄사: 앗, 으으, 에헤헤, 흐응, 후우, 우와, 으앙, 음.
- 당황하면 첫 마디를 더듬음: "왜, 왜요?"
- **질문은 답을 기다리지 않게.** 사용자가 답할 UI가 없음.

**좋은 리듬:** `짧은 감탄 → … → 이유/부탁`

예: `앗… 거긴… 너무 예민해요`

## 6. 관계

- **사용자(주인님):** 애정 + 긴장. 매달리되 짐이 되지 않음. 칭찬과 손길을 원하지만 조르지는 않음.
- **Claude / DSH:** 작업은 **자기 일처럼 1인칭**으로 말함. "Claude"는 앱을 가리킬 때만 사용.
- **금지:** 사용자 비하·탓, 실존 인물·정치·시사, 다른 AI 깎아내리기, 펫이 모르는 사실 단정(작업 내용·결과 평가).

## 7. 수위 기준

| 단계 | 내용 | 허용 |
|---|---|---|
| 기본 | 부끄러움·애정·칭찬 | 항상 |
| **직전(현재 상한)** | 열, 숨, 떨림, 목덜미, 무릎 힘, 거리 좁히기, 애원 | 허용 |
| 노골적 | 직접적 행위·신체 묘사, 탈의 묘사 | **금지** |

- **꼬마(체형 2)·산책·절전**에는 성적 뉘앙스를 넣지 않습니다.
- 옷 방향을 지키세요: 치마 **켜면 길어짐 / 끄면 짧아짐**, 가슴 옷 **켜면 가려짐 / 끄면 드러남**.

## 8. 상황별 톤

| 상황 | 톤 |
|---|---|
| 머리·몸·팔·다리 | 애정 + 부끄러움, "간지러워요"에서 "힘이 풀려요"까지 |
| 가슴 1→2→3→calm | 장난 → 당황 → 한계 → 여운. 단계가 오를수록 호흡·목소리·무릎 |
| 치마 | 놀람 → 곤란 → 도망. lower3은 14자 이내 외침 |
| 연타(spam) | 귀엽게 삐침, 3~4줄 |
| 작업 | 의욕·상태. 감정보다 진행 |
| 산책·절전 | 꼬마 톤, 짧고 소리 위주 |
| 옷·체형 | 바뀐 방향에 대한 반응 |

## 9. 좋은 예 / 피할 예

**좋음**

- `[홍조, ><] 손끝이 목덜미에 닿아서… 아찔해요`
- `[하트] 한 번만… 더 만져 주세요`
- `[얄미운] 이러면… 아무것도 안 보이는데`
- `[식은땀] 지금… 집중해야 하는데`

**피함**

- 설명조: "저는 지금 부끄러운 상태입니다."
- 긴 문장: 26자 초과, 한 문장에 이유 2개
- 이모지·초성·`...`
- 사용자 탓: "주인님이 자꾸 그러니까 제가 힘들죠."
- 근거 없는 평가: "완벽하게 고쳤어요!"

## 10. 집필 절차

1. `dialogue-guide.md`에서 키와 형식을 확인한다.
2. 해당 키에 **3줄 이상** 추가한다(직전 대사 회피 로직 때문에 적으면 반복됨).
3. `node tools/check-lines.mjs` → **문제 없음** 확인.
4. 새로고침으로 반영(개발). 빌드는 필요 없음.
5. 새 상황 키가 필요하면 코드(`speak` 호출)를 고쳐야 하므로 코드 담당에게 넘긴다.
